Groundline

Playable 3D sector from OpenStreetMap geometry, elevation, and satellite or a user aerial photo.

Live site (GitHub Pages):
https://paramedic-il.github.io/groundline-3d/

GovMap API domain to register:
paramedic-il.github.io

The game files are in dist/. Locally:

  node serve.mjs

Then open http://127.0.0.1:4173/

Do not open index.html as a file; modules need a web server.
See dist/credits.html for data licenses.
